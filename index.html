Welcome. The purpose of this website is to record my learning in networking, python and eventually, cybersecurity. For the next year or so (until I get my CCNA) I'll be primarily focusing on networking. > About

This is a running projects/lab page for networking, python and eventually, cybersecurity. This website is mainly for my own learning, keeping track of progress and I intentionally keep it really simple because it's easier for me to maintain, I plan on always keeping it this way.

I don't use AI in any of my projects or writing, the only thing I use it for is for all HTML, CSS and everything related to the appearance and behind the scenes of this website, that's it.
